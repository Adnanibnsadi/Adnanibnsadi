## 🔐 Featured Projects

### 🛡️ Wireless Intrusion Detection System
**Hybrid Wi-Fi WIDS for Evil Twin and BSSID-spoofed access point detection**

A research-oriented wireless security prototype that passively analyzes IEEE 802.11 beacon frames and builds behavioral profiles for nearby access points.

**Key work:**
- Live 802.11 beacon capture using Scapy and monitor mode
- Multi-access-point behavioral profiling
- SSID/BSSID consistency analysis
- Information Element (IE) fingerprinting
- Sequence-number collision and anomaly detection
- Timing and clock-skew analysis
- Per-BSSID Isolation Forest anomaly models
- Multi-layer threat scoring and real-time alerting

**Technologies:** Python, Scapy, pandas, NumPy, scikit-learn, Kali Linux

➡️ [View Project](https://github.com/Adnanibnsadi/wids-evil-twin-detector)
