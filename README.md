### What I'm working on

**[Wireless Intrusion Detection System (WIDS)](https://github.com/Adnanibnsadi/wids-evil-twin-detector)**

This is my main cybersecurity project. I'm developing a Python-based prototype that monitors Wi-Fi beacon traffic and looks for signs of Evil Twin and BSSID-spoofing attacks.

The system uses Scapy, access-point profiling, sequence-number analysis, and Isolation Forest anomaly detection.

One challenge I encountered was dealing with unreliable timing measurements caused by channel hopping and running Kali Linux inside VMware. I made changes to how timing evidence is handled and am currently working on making the experiments more reproducible.
